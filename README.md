# nai_image_manager

## 업스케일 모델 관리

- 갤러리와 캔버스의 업스케일 창에서 기존 **Real-CUGAN / Waifu2x CUNet / Lanczos**를 계속 사용합니다. 로컬 AI 모델은 같은 창에서 다운로드·취소·삭제할 수 있습니다. 처리 중인 모델은 삭제하지 못하며 원본과 결과 이미지는 보존합니다.
- 선택 다운로드: 중간 확대용 **IllustrationJaNai V3 detail FDAT M 4×**, 최종 확대용 **AnimeSharp V4 RCAN 2×**. Windows NVIDIA GPU용이며 공용 실행 환경은 최초 한 번 약 2.7GB를 다운로드하고 설치 후 약 5.3GB를 사용합니다. 모델 다운로드는 별도이며 창에 합산 용량을 표시합니다. 두 번째 모델은 실행 환경을 재사용하고 마지막 새 모델을 삭제하면 함께 정리합니다. 이 선택 자료는 EXE 배포본에 포함하지 않습니다.
- 새 모델은 기본 배율로 한 번 처리한 뒤 요청한 크기로 조정합니다. 예: 640×2048 → 2560×8192 → 2500×8000, 편집한 2500×8000 → 5000×16000. 큰 이미지는 작은 조각으로 처리합니다.
- **NovelAI**는 저장된 API 키로 요청합니다. 원본 복사본을 가운데 기준으로 5:16으로 자르고, 가로·세로가 64의 배수인 입력(최대 960×3072)으로 줄여 2배 확대합니다. 실제 출력은 최대 1920×6144이므로 5000×16000 최종 출력용과 구분해야 합니다. 창에 표시되는 조정 크기와 Anlas 사용 가능성을 확인한 뒤 실행하며 실패한 유료 요청은 자동 재시도하지 않습니다.
- [waifu2x 웹사이트](https://unlimited.waifu2x.net/) 링크도 제공합니다. 이 사이트는 브라우저에서 처리하므로 PC 성능의 영향을 받습니다.

## 인페인팅 참고 이미지

- 캔버스 설정의 **인페인팅 참고 이미지 → 이미지 추가**에서 PNG·JPEG·WebP를 고릅니다. 이미지 전체가 들어오도록 비율을 유지해 축소하고 흰 여백 중앙에 배치합니다. 작은 이미지는 확대하지 않습니다. **참고 폭**은 설정 영역에서 기본 320px에서 64~1024px의 64px 단위로 바꿀 수 있습니다.
- **참조 영역 포함 표시**는 캔버스의 미리보기만 켭니다. 실제 요청에 넣으려면 인페인팅 버튼 근처의 **참고 이미지 포함**을 체크합니다. 참조 폭과 작업·요청 크기를 표시하며, 비용 확인에도 참조를 포함한 크기를 사용합니다.
- 참고 이미지는 왼쪽의 수정하지 않는 영역으로 전송하며 `split screen`을 요청 프롬프트에 자동 추가합니다. 응답에서는 참조 영역을 제거하고 원래 작업 크기·위치로 돌려놓습니다. 저장한 프롬프트 원문은 유지합니다.
- 참고 이미지와 폭은 캔버스 전체에서 하나를 공유하고 캔버스와 함께 저장됩니다. 프로젝트에 연결된 캔버스에서는 **프로젝트에 등록 / 프로젝트에서 가져오기**로 설정을 복사할 수 있으며, 가져온 뒤에는 캔버스별로 독립 편집합니다.

## daki 프로젝트

- 갤러리 **라이브러리 → daki → 프로젝트 추가**에서 이름을 입력해 프로젝트를 만듭니다. 기존 화면에서도 상단 daki 탭으로 열 수 있습니다.
- 이미지 **우클릭 → 프로젝트에 추가 · daki**에서 새 프로젝트를 만들거나 기존 프로젝트를 고른 다음, 앞면 또는 뒷면 후보로 추가합니다.
- 후보는 원본 위치에 연결합니다. 원본을 복사하지 않으며, **후보에서 제외**도 원본 이미지를 삭제하지 않습니다.
- 후보로 연결된 그림을 갤러리에서 삭제하거나 폴더째 삭제할 때 프로젝트명과 면을 표시하고 확인을 받습니다. 확대 보기의 빠른 삭제와 휴지통 비우기에도 적용됩니다. 탐색기 등 프로그램 밖에서 삭제한 파일에는 미리 경고할 수 없으며, 다음 조회에서 **원본을 찾을 수 없음**으로 표시합니다. 일반 이동·재분류로 바뀐 경로는 자동 추적하지 않습니다.
- daki는 갤러리 안에서 열립니다. 상단 도구와 라이브러리, 카드 디자인을 공유하고 **기존 화면 / 새 화면** 설정도 그대로 적용됩니다.
- **도구 → 설정 → daki 사용**에서 메뉴를 켜고 끕니다. 기본값은 켜짐이며, 꺼도 프로젝트와 후보 목록·삭제 경고는 유지됩니다.
- 프로젝트와 사용 설정은 프로그램 폴더의 `daki_projects.json`에 저장합니다. 업데이트 보호 및 기존 자료 가져오기 대상입니다.

구현 경계와 검증 방법은 [STRUCTURE.md](STRUCTURE.md)의 daki 프로젝트 항목을 참고하세요.

## 공유 그림체 테스트

- v1.3.2부터 공유 그림체·공유 테스트의 Hugging Face 연결은 잘못된 `SSLKEYLOGFILE` 경로 때문에 실패하지 않도록 전용 TLS 설정을 사용합니다. 인증서·호스트명 검증과 ZIP 크기·SHA-256 검증은 유지합니다. 관련 연결 코드는 `naim/hf_http.py`, 회귀 검증은 `tests/test_hf_http.py`에 있습니다.

- **daki → 공유 그림체 → 그림체 일람**에서 가져온 V5 원본 공유 그림체를 봅니다. **상반신**은 별도 폴더로 유지하며 일람에 섞이지 않습니다. 각 그림체의 대표 이미지와 설정을 표시하며, 실제 갤러리의 카드·열 배치·배율·고정 크기 설정을 사용합니다.
- **공유 그림체 최신화 → Hugging Face 새 그림체 추가**는 현재 저장소의 최신 이미지팩에서 V5 Full/Medium의 새 그림체만 추가합니다. 기존 그림체와 이미지는 덮어쓰거나 숨기지 않으며, 같은 게시물도 이미지별 그림체를 비교합니다. 다운로드·검증·필터 처리가 모두 끝나야 반영하고 실패·중지 시 기존 일람을 유지합니다. 상반신과 전신 Full·Medium 테스트는 그대로 유지합니다.
- Hugging Face와 아카라이브 기간별 가져오기 모두 실사 제외와 포함·제외 태그를 지원합니다. 포함/제외 버튼으로 넓은 입력란을 전환해도 양쪽 내용은 유지되고 함께 적용됩니다. 빈칸은 제한이 없으며, 필터 변경으로 기존 그림체가 사라지지 않습니다. 창을 닫으면 화면 왼쪽 아래에 진행·완료·오류가 표시됩니다. 앱 서버는 계속 실행되어 있어야 합니다.
- 두 가져오기는 **작가 태그 전체 조합**으로 중복을 비교합니다. `artist:` 없는 작가도 작가 사전으로 인식하며, 같은 조합의 순서·가중치·품질·네거티브 차이는 새 그림체로 추가하지 않습니다. 작가가 없으면 품질 태그를 뺀 화풍 태그 조합을 비교합니다. 서로 다른 작가 조합은 같은 게시물에서도 가져올 수 있고, 이미 저장된 항목과 테스트 기록은 그대로 유지합니다.
- 선택 옵션 **추천수 기준 이하: 게시물당 1개**는 기본으로 꺼져 있습니다. 기준은 10에서 원하는 정수로 바꿀 수 있으며, 켜면 해당 게시물에서 조건을 통과한 첫 그림체만 추가합니다. 이미 가져온 V5 그림체가 있는 글에서는 더 추가하지 않고 기존 자료는 유지합니다. 추천수 미확인 글은 제한하지 않습니다. Hugging Face에서는 같은 버전의 게시물 DB를 함께 확인합니다.
- 가져오기 진행은 **다운로드 → 파일 확인 → 그림체 검사 → 목록 반영 → 완료**로 표시합니다. 그림체 검사에서는 추가·제외 여부와 별개로 전체 이미지 중 확인을 마친 장수와 해당 단계의 진행률을 보여 줍니다. 추천수 자료를 사용하는 경우 해당 자료의 다운로드·확인 단계도 표시합니다.
- 각 그림체 카드와 **원본 설정**에 아카라이브 출처 채널·글 번호를 표시합니다. 출처 링크를 누르면 해당 원문을 새 탭에서 엽니다.
- **원본 설정**은 모델·크기·스텝·CFG·샘플러를 요약하고 **Base / Nega** 탭으로 원문 프롬프트를 전환합니다. 나머지 옵션과 원본 시드는 **세부 설정**을 펼쳐 확인합니다.
- 일람에서 이름 옆 체크박스로 여러 그림체를 선택한 뒤 **선택한 그림체 삭제**를 누릅니다. 검색 결과를 한꺼번에 선택하거나 선택을 해제할 수 있습니다. 삭제한 그림체는 목록과 이후 **전체 그림체로 테스트 만들기** 대상에서 제외됩니다. 원본 이미지와 이미 준비·생성한 테스트는 보존합니다.
- Hugging Face 가져오기는 **실사 그림체 제외**가 기본 체크되어 있으며, 해제하면 `photorealistic`·`realistic` 그림체도 포함합니다. 포함 태그는 가상 폴더의 검색 문법과 같습니다. `watercolor, sketch`는 모두 포함, `watercolor || sketch`는 하나라도 포함, `watercolor, sketch || ink`는 앞의 두 조건을 모두 만족하거나 `ink`를 포함하는 경우입니다. 공백·줄바꿈도 쉼표처럼 동작하므로 여러 단어로 된 태그는 `blue_hair`처럼 쓰며, `%문구%`는 부분 일치입니다. 제외 태그는 쉼표나 줄바꿈으로 구분하고 하나라도 정확히 일치하면 우선 제외합니다. 원본 긍정 프롬프트만 검사하고 네거티브는 검사하지 않습니다. 필터를 바꾸고 다시 갱신하면 같은 팩도 다시 판정합니다. 기존 상반신·아카라이브 수집의 실사 제외 규칙은 유지합니다.
- 같은 그림체와 동일 픽셀 이미지는 팩 안에서 중복 제외합니다. 기존 테스트·프로젝트 연결과 수동 제외 목록은 보존하며, 갱신으로 일람에서 빠진 이전 항목도 저장된 연결에서 조회할 수 있습니다.
- **공유 그림체 폴더 화면의 전체 그림체로 테스트 만들기**에서 공통 프롬프트·네거티브·캐릭터 프롬프트와 모델(V5 Full, V5 Full Medium, V4.5 Full)을 입력합니다. 공유 그림체 일람의 그림체에만 같은 입력을 더하며(상반신 제외) 고유 스타일, 크기, 스텝, CFG, 샘플러와 나머지 옵션은 그대로 유지합니다. 시드는 그림체 설정이 아니며 새 그림마다 무작위로 생성합니다. 원본 이미지 시드는 정보로만 보관합니다.
- **V5 Full Medium**은 모델 제약에 따라 14 스텝·Euler Ancestral·Karras를 고정 적용하고 CFG Rescale을 사용하지 않습니다. 그림체·공통·캐릭터 네거티브 대신 고정 네거티브를 사용합니다. 입력한 네거티브는 다른 모델로 전환하면 복원되며 원본 그림체 설정은 바꾸지 않습니다. 비용 경고와 결과 이미지 메타데이터에는 실제 적용 설정을 사용합니다.
- 생성 설정은 **모델·크기 / Base·Nega 프롬프트**를 나란히 보여줍니다. 크기는 원본 유지, NAIA와 같은 **Small·Normal·Large·Wallpaper 프리셋 30개**, 직접 입력 중 선택합니다. 가로·세로는 64~2048px의 64 배수, 전체 면적은 최대 1472×1472픽셀이며 가로·세로 교환도 가능합니다.
- 테스트 화면의 **설정 수정 → 남은 그림에 적용**으로 모델·프롬프트·크기를 다시 지정합니다. 생성 중이면 먼저 중지하고 현재 한 장의 저장이 끝난 뒤 수정합니다. 이미 완료되거나 실패한 항목은 바꾸지 않고 대기 항목만 새 설정을 적용하며, 결과 카드에 각 그림의 실제 모델과 크기를 표시합니다. 크기 변경 시 Anlas 허용은 다시 확인합니다.
- 짧게 왼쪽 클릭하면 확대하고 좌우 키로 이동합니다. 길게 왼쪽 클릭하면 기존 다이얼 태그 메뉴를 사용하며 태그가 저장됩니다. 우클릭으로 복사·저장·프롬프트·원본 경로 탐색·캔버스 가져오기·프로젝트 추가를 사용합니다. 참조 원본의 인페인팅·업스케일은 캔버스로 가져와 작업합니다.
- **다음 그림체 한 장 생성**, **남은 그림체 모두 생성**, **중지**를 사용합니다. 완성된 그림은 즉시 표시되고 자동 저장됩니다. 중지는 진행 중인 한 장을 저장한 뒤 다음 요청부터 멈추며, 저장된 테스트에서 이어갈 수 있습니다. **실패한 그림 다시 생성**은 실패한 항목만 저장된 설정과 새 시드로 재시도합니다. 키를 변경했다면 변경한 키를 사용하며 완료된 그림과 대기 중인 항목은 유지합니다. 실패하거나 실행 여부가 불확실한 요청은 자동 재시도하지 않습니다.
- 기존 그림체 원본은 같은 상위 폴더의 `dakiMaker/research/style-catalog`를 연결합니다. 이 폴더를 옮기면 원본 목록·이미지 연결이 끊깁니다. 새 테스트 결과는 NAIM의 `daki_style_tests`에 별도로 저장하며 업데이트·자료 가져오기 시 보존합니다.
- 가져온 V5 설정·썸네일·중복 목록은 `daki_imported_styles`에 보관하고 원본 이미지는 그림체 생성 프로젝트의 원래 위치에 연결합니다. 직접 삭제한 그림체 ID는 같은 폴더의 `excluded_styles.json`에 별도로 기록하여 재시작·다시 가져오기 후에도 제외합니다. 이 폴더도 업데이트·자료 가져오기 시 보존합니다.
