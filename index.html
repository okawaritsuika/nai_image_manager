🗂️ 가상 폴더 관리

실제 파일 위치는 변경되지 않습니다.
프롬프트를 입력하면 검색 결과를 동적으로 묶습니다. 비워 둔 폴더는 수동으로 사용할 수 있습니다.

쉼표·공백·줄바꿈=모두 포함, ||=하나 이상, %문구%=부분 일치 (예: %hair%). 여러 단어 태그는 blue_hair처럼 입력하세요.

프롬프트 입력 방법

쉼표·공백·줄바꿈은 AND로 묶고, ||는 OR 그룹을 나눕니다.

  • watercolor, sketch — 두 태그 모두 포함
  • watercolor || sketch — 둘 중 하나 포함
  • watercolor, sketch || ink — 앞의 두 태그 모두 포함하거나 ink 포함

%hair%는 hair 부분 일치입니다. 여러 단어 태그는 blue_hair처럼 밑줄로 연결하세요.
