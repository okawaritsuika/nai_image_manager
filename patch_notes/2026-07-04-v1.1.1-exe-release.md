# NAI Image Manager v1.1.1 EXE

갤러리에서 이미지 태그를 더 빠르게 부여할 수 있는 태그 모드를 추가했습니다.

## 주요 변경사항

- 도구 메뉴에 `태그 모드`를 추가했습니다.
- 태그 모드가 켜진 상태에서 그림체 필터 아래의 태그를 클릭하면 필터링 대신 부여할 태그가 선택됩니다.
- 태그를 선택한 뒤 갤러리 이미지를 클릭하면 해당 이미지에 태그가 즉시 지정됩니다.
- `태그 없음`을 선택하고 이미지를 클릭하면 기존 태그를 제거할 수 있습니다.
- 태그 모드가 켜지면 삭제 모드처럼 화면 하단에 상태 창이 표시됩니다.
- 삭제 모드와 태그 모드가 동시에 켜지지 않도록 처리했습니다.

## 업데이트 안내

이미 v1.1.0 EXE 버전을 사용 중이면 앱 안의 `업데이트 확인` 버튼으로 업데이트할 수 있습니다.
업데이트는 GitHub Release ZIP을 내려받고 SHA-256을 검증한 뒤 프로그램 파일만 교체합니다.

## 사용자 데이터 보존

이번 업데이트는 기존 사용자 데이터를 변경하지 않습니다. 다음 항목은 업데이트 시 보존됩니다.

- `TOTAL_CLASSIFIED` 이미지 라이브러리
- `gallery_config.json`, `gallery_image_tags.json`
- `artists.json`, `styles.json`, `quality_presets.json`
- `canvas_saved_setups.json`, `tag_dictionary_user_overrides.json`
- 그 밖의 사용자 설정, 출력 파일, 작업 폴더

## 새로 설치하는 방법

1. `NAI_Image_Manager_v1.1.1-exe_windows.zip`을 다운로드합니다.
2. 원하는 위치에 ZIP 전체를 압축 해제합니다.
3. 폴더 안의 `NAI_Image_Manager.exe`를 실행합니다.

EXE 파일만 따로 꺼내지 말고 압축 해제된 폴더 구조를 유지해 주세요.
