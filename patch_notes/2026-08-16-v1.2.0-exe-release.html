NAI Image Manager v1.2.0 EXE

날짜: 2026-08-16

요약

갤러리 탐색과 캔버스 작업을 확장하고, 저장된 검색을 가상 폴더로 관리할 수 있도록 개선했습니다. Waifu2x 업스케일 엔진도 추가되어 Real-CUGAN, Waifu2x, Lanczos 중 작업에 맞는 방식을 선택할 수 있습니다.

주요 변경사항

1. 갤러리 보기와 검색 확장

  • 캐릭터별 보기 외에 날짜별 보기(월·주·일)를 추가했습니다.
  • 폴더를 여러 개 선택해 한 화면에서 통합해서 볼 수 있습니다.
  • 이미지가 많은 폴더는 화면에 필요한 만큼 나누어 표시하고, 사용자 지정 스크롤 안내를 제공합니다.
  • 검색어는 공백·쉼표로 AND 검색을 하며, ||로 OR 조건을 만들 수 있습니다.
  • %문구% 형식으로 프롬프트 일부를 검색할 수 있습니다.
  • 이미지를 길게 누르면 다이얼 메뉴에서 갤러리 태그를 빠르게 지정하거나 제거할 수 있습니다.

2. 가상 폴더

  • 실제 파일을 이동하지 않고 프롬프트 검색 조건을 가상 폴더로 저장할 수 있습니다.
  • 가상 폴더를 중첩하고, 검색 범위와 VIEW 모드를 지정하며, 이름·조건·상위 폴더를 나중에 수정할 수 있습니다.
  • 검색 결과는 인덱스 상태에 맞춰 캐시되며, 조건이나 프롬프트 인덱스가 바뀌면 다시 계산됩니다.
  • 가상 폴더에 포함되지 않은 결과를 미분류 보기에서 확인할 수 있습니다.

3. Waifu2x 업스케일

  • 업스케일 엔진에 Waifu2x CUNet을 추가했습니다. 선화 보존과 노이즈 억제가 필요한 이미지에 사용할 수 있습니다.
  • 기존 Real-CUGAN과 빠른 Lanczos 리사이즈도 계속 사용할 수 있습니다.
  • 배포 ZIP에는 Real-CUGAN과 Waifu2x 실행 파일 및 모델이 포함되어 있어, 압축 해제 후 별도 다운로드 없이 선택할 수 있습니다.
  • 업스케일 엔진은 Windows용 Vulkan 실행 파일을 사용하므로 그래픽카드와 드라이버에 따라 처리 속도가 달라질 수 있습니다.

4. 캔버스 작업 개선

  • 큰 이미지는 캔버스 표시용 preview를 사용해 초기 표시와 레이어 목록의 부담을 줄였습니다.
  • EXIF 방향을 반영해 외부 이미지의 표시 크기와 방향을 보정합니다.
  • 레이어 이동·크기 조절·클립 마스크 편집의 화면 갱신을 정리해 드래그 작업을 더 안정적으로 처리합니다.
  • 참조 이미지 생성 화면에 확대·브러시 마스크·선택 영역 표시를 보강했습니다.
  • 원본 디테일 편집에서 얼굴·눈 영역용 ChatGPT 수정 프롬프트를 만들고 복사할 수 있습니다.
  • 참조 이미지와 인페인팅 결과를 캔버스 레이어 또는 선택 영역 안의 클립으로 내보낼 수 있습니다.

5. 안정성 개선

  • 삭제 작업 중 Windows 콘솔 인코딩이 로그 문자를 처리하지 못해도 파일 작업이 중단되지 않도록 보완했습니다.
  • 프롬프트 인덱스 검색과 파일 시스템 fallback이 같은 검색 규칙을 사용하도록 정리했습니다.

업데이트 방법

  1. 기존 v1.1.1 EXE 사용자는 앱의 업데이트 확인 기능을 사용할 수 있습니다.
  2. 업데이트 파일은 GitHub Release ZIP을 내려받은 뒤 SHA-256을 확인하고 프로그램 파일만 교체합니다.
  3. 직접 업데이트하려면 위 ZIP을 내려받아 기존 설치 폴더에 압축을 풀고 NAI_Image_Manager.exe를 실행하세요.
  4. 압축 안의 폴더 구조와 NAIM_Updater.exe를 유지해야 하며, EXE 파일만 따로 꺼내 실행하지 마세요.

처음 설치하는 방법

  1. NAI_Image_Manager_v1.2.0-exe_windows.zip을 원하는 위치에 전체 압축 해제합니다.
  2. 압축 해제된 폴더 안의 NAI_Image_Manager.exe를 실행합니다.
  3. 압축 해제 후 폴더 구조를 유지하고, NAI_Image_Manager.exe만 따로 꺼내 실행하지 마세요.
