사용법 · 단축키

Ctrl+Z: 레이어·선택 영역·클립 편집 실행 취소. 입력란에서는 글자 편집을 취소합니다. 다른 캔버스를 불러오면 기록이 초기화됩니다.

레이어 이동

이동 버튼을 켜고 레이어를 드래그하거나 방향키로 이동하세요. Shift를 누르면 큰 간격으로 이동합니다.

그림 지우개

그림 레이어를 선택하고 지우개를 켠 뒤 드래그하세요. Ctrl+Z로 지우기를 되돌립니다.

그림 크기 조절

버튼을 켠 뒤 이미지 레이어를 선택하고 가장자리/모서리를 드래그하세요. Alt를 누르면 더 세밀하게, Shift를 누르면 비율 유지 없이 조절합니다.

캔버스 크기 조절

버튼을 켠 뒤 캔버스 오른쪽/아래쪽/오른쪽 아래 핸들을 드래그하세요.

선택 영역 표시

선택 영역 박스만 숨기고 인페인팅 결과를 확인합니다.

인페인팅 설정

캔버스 전체에서 공유할 모델과 인페인팅 생성 값을 설정합니다.

현재 캔버스 저장

캔버스 크기, 레이어, 선택 영역, 인페인팅 결과와 프롬프트 제어 그룹을 저장합니다.

통합 내보내기

현재 캔버스에 보이는 이미지와 인페인팅 결과를 합쳐 내보냅니다. 프로젝트에 연결되어 있으면 저장 위치를 선택합니다.
